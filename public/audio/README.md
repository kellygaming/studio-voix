# Extraits de démonstration (avant / après)

La section « Écoutez la différence » de la page d'accueil lit deux fichiers :

| Fichier | Contenu attendu |
|---|---|
| `avant.mp3` | L'enregistrement brut, avec le bruit de fond (voiture, frigo, souffle). |
| `apres.mp3` | **Le même extrait**, passé dans Studio Voix. |

## Conseils

- **8 à 15 secondes**, pas plus : c'est une preuve, pas une démo produit.
- **Le même passage, le même texte, le même volume perçu** dans les deux fichiers.
  Si « après » est simplement plus fort, l'oreille croit à une amélioration qui n'existe pas —
  et un visiteur venu d'une publicité le sent tout de suite.
- MP3 mono, 96 kbps suffit largement (~120 Ko par fichier). Le but est que ça démarre
  instantanément sur une connexion mobile.

Tant que les fichiers ne sont pas là, la section reste affichée mais les deux lignes
se désactivent avec la mention « Extrait bientôt disponible » : aucune fausse promesse.
